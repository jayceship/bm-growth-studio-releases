스레드-스마트스토어 자동화는 브랜드 "봉명"의 마케팅을 돕는 내부 도구예요. 이 서비스에 저장된 내 정보를 지우고 싶다면 아래 방법으로 요청해 주세요. 어떤 정보를 다루는지는 개인정보처리방침에 있어요.

삭제를 요청하는 방법

  1. [연락 이메일] 로 이메일을 보내 주세요.
  2. 제목에 "데이터 삭제 요청"이라고 적어 주세요.
  3. 본문에 Threads 사용자 이름(예: @username)을 적어 주세요. 스마트스토어 구매 정보라면 주문 때 쓴 이름과 주문 날짜를 적어 주세요.
  4. 본인 확인을 위해 필요한 경우에만 추가 정보를 여쭤봐요. 주민등록번호나 비밀번호는 절대 묻지 않아요.

무엇이 지워지나요

  • 서비스에 저장된 내 공개 게시물의 글, 게시물 주소, 사용자 이름
  • 내 게시물을 바탕으로 만든 분류 결과, 답글 초안, 메모
  • 스마트스토어 자료 안의 내 구매자 정보 (이름, 연락처, 배송지)
  • 삭제 뒤에는 내 계정을 추천 대상에서 빼서, 다시 저장되지 않게 해요.

Threads나 스마트스토어에 올라가 있는 원래 게시물·주문은 이 서비스가 지울 수 없어요. 그건 각 플랫폼에서 직접 지워야 해요. 다른 법령이 일정 기간 보관을 요구하는 정보는 그 기간이 끝난 뒤 지워요.

얼마나 걸리나요

요청을 받은 날부터 10일 안에 지우고, 결과를 이메일로 알려 드려요. 백업 파일에 남은 사본은 [보유 기간] 안에 백업 주기에 따라 함께 지워져요.

Threads 연결을 끊은 경우 (운영자 계정)

운영자가 Threads 설정에서 이 앱의 권한을 지우면(설정 → 계정 → 웹사이트 권한 → 활성 → 삭제), 서비스는 저장된 접근 토큰을 지우고 더 이상 Threads 정보를 받지 않아요.

How to request deletion

  1. Email [Contact email].
  2. Use the subject line "Data deletion request".
  3. Include your Threads username (for example @username). For store purchase data, include the name used on the order and the order date.

When the account owner removes this app in Threads (Settings → Account → Website permissions → Active → Remove), the Service deletes the stored access token and stops receiving Threads data.
